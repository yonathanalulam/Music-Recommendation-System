# Music-Recommendation-System that recommends music based off of data from [Kaggle](https://www.kaggle.com/datasets/notshrirang/spotify-million-song-dataset/data) 
Program takes a random sample from the data it has, and then uses lyrics that've been properly cleaned up as a basis for recommeneding similar songs.
  The recommendation is based on on cosine similarity which's usually used in natural language processing to find similar texts. The program takes advantage of this to find songs with similar lyrics.
