# Music-Recommendation-System that recommends music based off of data from [Kaggle](https://www.kaggle.com/datasets/notshrirang/spotify-million-song-dataset/data) 
The program basically uses lyrics that've been properly cleaned up as a basis for recommeneding similar songs.
  The recommendation is based on on cosine similarity which's usually used in natural language processing to gauge the similarity of different clusters of texts by analysing their content. The program takes advantage of this to find songs with similar/ similar meaning lyrics.



necessary packages/libraries
streamlit
pandas
scikit-learn
nltk
joblib

Dataset can either be directly downloaded from [Kaggle](https://www.kaggle.com/datasets/notshrirang/spotify-million-song-dataset/data). If the file size is inconvenient you can generate an API key from there and incldue it in your project.
